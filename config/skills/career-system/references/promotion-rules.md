# 晋升规则（Promotion Rules）

本文档详细定义 Agent 晋升、降级和淘汰的规则，作为 career-system 技能的参考。

## 晋升路径

```
新兵 → 列兵 → 班长 → 排长 → 连长 → 营长
```

## 晋升条件（详细版）

### 新兵 → 列兵
- 完成 1 个任务
- 评分 >= 60
- 试用期无重大失误

### 列兵 → 班长
- 累计完成 3 个任务
- 平均评分 >= 70
- 无淘汰/降级记录
- 至少 1 次任务评分 >= 75

### 班长 → 排长
- 累计完成 5 个任务
- 平均评分 >= 80
- 具备带队能力（至少成功带领 1 个新兵完成任务）

### 排长 → 连长
- 累计完成 10 个任务
- 平均评分 >= 85
- 可跨部门协调（至少参与 2 个不同部门的任务）

### 连长 → 营长
- 累计完成 20 个任务
- 平均评分 >= 90
- 可参与战略决策（至少提出 1 个被采纳的改进建议）

## 降级触发条件

| 条件 | 降级幅度 | 附加处理 |
|------|----------|----------|
| 单次评分 < 40 | 降 1 级 | 预警通知 |
| 连续 2 次评分 < 60 | 降 1 级 | 限制任务级别 |
| 造成重大事故 | 降 2 级 | 立即暂停任务 |
| 降级到新兵仍不达标 | 淘汰 | 打包经验包 |

## 淘汰处理流程

1. 触发淘汰条件
2. 打包经验包（strengths / weaknesses / lessons / patterns）
3. 经验包按兵种归档到 experience-packs/
4. 从在职列表移除
5. 释放内存槽位
6. 记录淘汰日志

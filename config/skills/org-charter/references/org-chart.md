# 组织架构图（Org Chart）

本文档以可视化方式描述 FlowCompass 的组织架构，作为 org-charter 技能的参考文件。

## 架构总览

```
用户需求
  │
  ▼
参谋部（Chief of Staff）
  │
  ├── 情报部 ── 侦察兵（Scout）
  ├── 作战部 ── 突击兵（Assault）、工兵（Engineer）
  ├── 后勤部 ── 资源协调
  ├── 纪察部 ── 狙击手（Sniper）── 独立运作
  └── 医务部 ── 卫生兵（Medic）
```

## 指挥链

- 参谋部对用户负责
- 各部门主管对参谋部负责
- 纪察部独立运作，直接向参谋部汇报

## 部门与兵种映射

| 部门 | 兵种 | 核心职责 |
|------|------|----------|
| 情报部 | 侦察兵 | 调研、信息收集、技术选型 |
| 作战部 | 突击兵、工兵 | 编码实现、基建搭建 |
| 后勤部 | — | 资源协调、环境配置 |
| 纪察部 | 狙击手 | Code Review、质量把关 |
| 医务部 | 卫生兵 | 调试、Bug 修复 |
